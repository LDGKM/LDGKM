#### Three studies with public code and a written report

| Project | Question | Result |
|---|---|---|
| [**From data to robust surgery schedules**](https://github.com/LDGKM/surgery-duration-uncertainty) · research | How uncertain is an operation's duration, and what does learning that uncertainty change in an operating-room schedule? | Conformalized quantile regression reaches 80.1% coverage (historical percentiles: 76.5%); planning at the learned 80th percentile cuts overtime from 113 to 19 min per room and day. [Report](https://github.com/LDGKM/surgery-duration-uncertainty/blob/main/report/report.pdf) |
| [**Road accidents in France, 2019–2024**](https://github.com/LDGKM/road-accidents-france) · data analysis | When, where and to whom do road deaths happen, and what makes a crash fatal? | 310,000 accidents cleaned in SQL, death counts matching official ONISR figures (2019–2023); logistic regression (AUC 0.76); under-recording found in Mulhouse. [Report](https://github.com/LDGKM/road-accidents-france/blob/main/report/report.pdf) |
| [**What France reimburses, 2019–2025**](https://github.com/LDGKM/medicine-spending-france) · data analysis | Where does the growth in medicine spending come from? | €160 bn analysed: spending +43% with flat volumes; molecules linked across ATC code changes; age-standardised regional comparison. [Report](https://github.com/LDGKM/medicine-spending-france/blob/main/report/report.pdf) |

Everything reruns with one command (`python run_all.py`) and gives the same numbers.
